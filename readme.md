# Emoji Crypt Tool

A zero-width steganography tool to hide secret messages inside emoji sequences.  
Optional AES encryption adds an extra layer of security.

## Features

- Encode messages inside emojis
- Decode hidden messages
- Optional AES-256 encryption
- Copy encoded/decoded messages to clipboard

## How to Use

1. Open `index.html` in your browser.
2. Enter cover emojis and your secret message.
3. Click **HIDE** to encode, or paste an encoded string and click **REVEAL** to decode.
